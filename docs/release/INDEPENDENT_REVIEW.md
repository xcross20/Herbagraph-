# Independent human review before MVP acceptance

CI can prove fixtures. It cannot replace these reviews.

## Founder gold workflow

The Founder completes, without developer interpretation:

1. Burning feet + normal EMG
2. Gallbladder concern + unrelated EMG
3. A→B→A correction and return visit
4. Safety escalation follow-up
5. No-change monitoring

Pass only if the Founder can say why each branch is open and what would change it.

## Clinician / research review

Check coverage semantics, citation fidelity, and that non-addressing tests stay non-closing.

## Security / privacy review

Tenant isolation, PHI in logs/prompts/exports, and that tripwires never emit narratives.

## Stranger reconstructability

A reviewer who did not implement the system must reconstruct each material conclusion from persisted provenance.

None of these reviews is complete until written against an exact SHA.
